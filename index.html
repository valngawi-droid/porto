04 — Alur rilis

Dari commit sampai HTTPS.

  1. Push ke main di GitHub.
  2. Actions merakit file statis dan rsync ke VPS.
  3. Nginx menyajikan situs di /var/www/porto.
  4. Certbot menjaga sertifikat Let’s Encrypt tetap hidup.
